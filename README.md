# 🎵 Bluzic — Bluetooth Audio Receiver для Windows 10/11

**Bluzic** (сокращение от *Bluetooth + Music*) — современное легковесное приложение для Windows 10 (билд 19041+) и Windows 11, которое превращает ваш ПК или ноутбук в беспроводную Bluetooth-колонку для приёма аудио со смартфонов, планшетов и других устройств.

---

## 🚀 Основные возможности

* 📱 **Bluetooth A2DP Sink (Приём аудио):** Стриминг высококачественного звука со смартфона (Android, iOS) напрямую в колонки или наушники ПК с минимальной задержкой.
* ⚡ **Автоподключение (Auto-Connect):** Автоматический захват аудиопотока при появлении знакомого сопряжённого устройства.
* 🔊 **Раздельная регулировка громкости:** Управление громкостью конкретно входящего Bluetooth-потока / приложения без изменения общей системной громкости Windows.
* 📌 **Фоновый режим и системный трей:** Сворачивание в область уведомлений при закрытии, контекстное меню быстрого отключения/включения звука.
* 🚀 **Автозапуск с Windows:** Опция запуска в свёрнутом виде при старте операционной системы.
* 🎨 **Windows 11 Fluent Design:** Чистый интерфейс в тёмных тонах со скруглёнными карточками и статус-индикаторами.

## 🛠 Как пользоваться

1. **Первое сопряжение:**
   * Включите Bluetooth на телефоне и ПК.
   * Выполните стандартное сопряжение в *Параметрах Windows -> Bluetooth и устройства* (можно открыть кнопкой «⚙ Настройки BT» в приложении).
2. **Подключение:**
   * Откройте **Bluzic** — сопряжённый телефон появится в списке.
   * Нажмите **«Подключить»** (или включите «⚡ Автоподключение»).
3. **Воспроизведение:**
   * Включите любой трек, видео или подкаст на телефоне — звук польётся из динамиков вашего компьютера!

## 💻 Сборка из исходников

### Требования
* Windows 10 (версия 2004 / 19041+) или Windows 11
* .NET SDK 8.0 / 9.0 / 10.0

```bash
# Клонирование / переход в папку
cd Bluzic

# Сборка проекта
dotnet build

# Релизная публикация в единый .exe файл
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o "Publish"
```
